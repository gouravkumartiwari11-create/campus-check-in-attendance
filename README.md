# Campus Check-In

A student-made attendance management project with a small, colorful website
and a syllabus-aligned C console program.

## Open the website

Open `index.html` in a browser. The demo has no server, build step, or
third-party dependencies.

The website includes fictional sample students, daily present/absent totals,
check-in feedback, duplicate-check-in prevention for the current demo day,
and a button to restore the sample attendance. Demo changes are stored only
in the current browser.

## C program

`attendance.c` is the C console version. See [README.txt](README.txt) for
compiler instructions and details about its PIN-based check-in.

## Important limitations

This project is for learning and demonstration, not real attendance records.
The website does not authenticate students or verify identity, prevent proxy
attendance, or protect browser-stored data from editing. Use fictional data
only; real identity checks require in-person supervision or a separate,
appropriate verification system.
